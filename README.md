## 📖 Overview
The React Quiz challenges users with a series of multiple-choice questions about React.js concepts.  
Users receive instant feedback and a final score at the end, designed to practice key React and TypeScript fundamentals.

---

## ✨ Features
- 🧠 15 multiple-choice React.js questions  
- ⚡ Real-time scoring with instant feedback  
- 💾 Global state management using Context API  
- 💡 Typed components with TypeScript  
- 📱 Fully responsive design built with CSSModules  

---

## 🧠 Technical Implementation
Built with **React + TypeScript** for type safety and better developer experience.  
Global state is managed with **Context API**, and **useEffect** handles side effects such as fetching questions.  
Local state tracks user selections and scores.  
Styling handled by **TailwindCSS** for a modern, responsive interface and deployed via **Vercel**.
